## 周期测量下量子环的最少探测位置

对最近邻跃迁圆环，要求同一组探测位置对任意初态、任意固定正测量周期都保证最终探测。对至少五个格点的圆环，笔记推导出最少探测点数为 4、6 或 8，取决于环长的整除性。证明将相位重合问题归约到单位根关系，再用精确整数运算验证有限情形。

## 随机区间子序列的兼容性

每个区间由两个独立均匀端点生成。用同一组代表值分别优化至多 \(k\) 条和至多 \(\ell\) 条不降子序列的覆盖量，其中 \(k\le \ell\)。两项能同时达到各自的渐近最优值，当且仅当 \(k+1\) 整除 \(\ell+1\)。一条和两条共用选值时，两项最优比例之和损失 \(1/42\)。笔记给出一般权重下的损失公式和五组静态枚举复核。
